1. What exactly is TCS NQT?

TCS NQT is an entry-level assessment used in TCS hiring. For the latest official All India NQT hiring notice currently available, TCS describes an integrated test with Foundation and Advanced sections, followed by interview selection based on performance and the hiring process.

OFFICIAL • 2026

75 min

Numerical Ability 25 min • Verbal Ability 25 min • Reasoning Ability 25 min

2. End-to-end hiring flow

Think of the process as a pipeline. The exact interview sequence can vary by drive, so use the interview stages below as preparation categories rather than a guaranteed fixed order.

01

Eligibility

Check the specific drive notice, academics, backlog, education, gap and other criteria.

02

Apply

Register/login on TCS NextStep under IT and complete the drive application when applicable.

03

NQT

Take the Foundation + Advanced integrated assessment when the drive requires it.

04

Shortlisting

Test performance and eligibility determine the next stage. TCS identifies candidates for relevant hiring categories.

Technical interview

Prepare Java/programming, OOP, DBMS, OS, CN, coding, resume and projects.

Managerial / discussion

Be ready for teamwork, ownership, conflict, prioritization, communication and project situations.

HR / final discussion

Prepare introduction, career goals, relocation, joining, strengths/areas to improve and company awareness.

Important: The current official 2026 notice says shortlisted candidates receive further communication on next steps. It does not guarantee that every candidate will have three separately named TR/MR/HR rounds.

4. February 2027 master roadmap

Finish Foundation first, build DSA steadily, then move into Advanced and timed practice. Do not wait until January to start coding.

OCTOBER

Foundation Phase

Quant basics + reasoning basics + verbal every day. Arrays, strings, hashing and Java collections.

NOVEMBER

Core DSA Phase

Binary search, sorting, linked lists, stack, queue, sliding window and two pointers. Continue aptitude.

DECEMBER

Core + CS Phase

Trees, greedy, bits, heap, basic DP. Complete OOP, DBMS/SQL, OS and CN first-pass revision.

JANUARY

Advanced + Mock Phase

Advanced quant/reasoning, coding under time, mixed mocks, error log, interview and project revision.

OCT 1–2
Quant + reasoning foundation

Percentages, ratio/proportion, averages, profit/loss, simple & compound interest, number system, HCF/LCM, simplification, series, coding-decoding, directions and basic syllogisms. Verbal: grammar + vocabulary + 15 minutes reading daily.

OCT 3–4
Complete Foundation + Arrays/Strings

Time & work, pipes, time-speed-distance, trains, mixtures, data interpretation, arrangements and blood relations. Coding: arrays, strings, frequency counting, HashMap, HashSet, two pointers, prefix sum, Kadane. Target: 25–35 coding problems.

NOV 1–2
Sorting + Binary Search

Bubble/selection/insertion concepts, merge/quick concepts, standard binary search, lower/upper bound, search insert position, rotated array, peak element, square root. Target: 15–20 focused problems.

NOV 3–4
Linked List + Stack + Queue

Reverse, middle, cycle, merge lists, remove nth node, parentheses, next greater element, queue/circular queue and Java collections. Start timed 30-minute coding sets.

DEC 1–2
Sliding Window + Trees

Fixed/variable windows, longest substring, max sum K, two pointers, binary tree traversals, DFS/BFS, level order, height/depth and BST basics.

DEC 3–4
Greedy + Bits + Heap + DP

Activity selection, intervals, XOR, set bits, power of two, PriorityQueue, K largest/top K, Fibonacci DP, climbing stairs and house robber. First-pass CS fundamentals: OOP, DBMS/SQL, OS, CN.

JAN 1–2
Advanced Quant + Advanced Reasoning

Mixed difficult arithmetic, DI, logical puzzles, arrangements and data sufficiency. Start full 190-minute simulation every week. Coding: medium-level array/string/hashmap/BS/stack problems.

JAN 3–4
Mock + interview bootcamp

2 full mocks/week, deep error analysis, coding under 90-minute Advanced-style practice, resume drill, project explanation, Java/OOP/SQL technical questions and HR/managerial answers.

FEB
Final revision / exam window

No major new topics. Revise formula sheet, reasoning shortcuts, vocabulary, DSA patterns, CS notes and error log. Take only controlled mocks and protect sleep. Adjust the exact exam week when TCS publishes your drive schedule.

Completion rule: A topic is “complete” only when you can explain the concept, solve 5–10 representative questions without help, code the standard pattern in Java, and solve at least one timed problem using it.

8. Interview preparation

Do not wait until after the OA. Spend a small amount of time each week building interview readiness.

Prepare OOP deeply; Java collections and exceptions; SQL queries and DBMS; OS processes/threads/deadlocks; CN basics; coding on arrays/strings/hash maps/linked lists; and every project/resume line.
Prepare examples for teamwork, disagreement, deadline pressure, taking ownership, learning a new technology, debugging a difficult issue and handling changing requirements. Use Situation → Task → Action → Result.
Prepare a 60–90 second introduction, strengths and improvement areas, why TCS, career goals, relocation/availability questions, academic explanation if needed, and questions you want to ask the interviewer.
1) Problem and users → 2) Why you chose it → 3) Architecture → 4) Frontend → 5) Backend/API → 6) Database → 7) Authentication/security → 8) Your individual contribution → 9) Biggest bug/challenge → 10) What you would improve.
